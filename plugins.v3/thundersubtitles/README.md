# 迅雷字幕 · MoviePilot V3

适用于 MoviePilot **3.2.3 及以上版本**，插件版本 **2.1.0**。
沿用 V2 的 `ThunderSubtitles` 插件 ID 和配置字段，使用 V3 稳定 SDK、类型化整理事件和宿主调度任务。

## 安装

在插件市场中添加同一个仓库地址：

```text
https://github.com/lj0014/MoviePilot-Plugins/
```

刷新市场，安装或更新「迅雷字幕」。V2 读取 `package.v2.json` 和 `plugins.v2/`，
V3 读取 `package.v3.json` 和 `plugins.v3/`。两版可以在同一个插件源仓库维护，
宿主按自己的版本选择实现，同一宿主无需同时安装两份。

从已安装 V2 插件的宿主升级时，已有偏好、路径、cron 和下载记录格式保持兼容。
插件自身不修改 MoviePilot 的数据库结构。是否升级主程序及其配置迁移由用户另行操作。

## 使用

- 启用后处理新入库的本地电影、剧集；下载任务由 MoviePilot 宿主调度。
- 补全已有影片时，填写容器内扫描目录，勾选「保存后扫描一次」后保存；也可配置 cron。
- 新配置默认中英双语优先，已有配置保留原偏好。先按版本线索排序，再按语言偏好选择。
- 字幕保存为 `影片名.zh.srt`、`影片名.zh.ass` 等文件；默认跳过已有中文字幕，始终保留同名文件。
- 查询合并 CID 和名称结果，使用原始文件名及入库后文件名补搜。详情页保留最近 50 条记录。
- 调度器尚未就绪时，手动扫描开关不会被清除；稍后重新保存配置即可重试。
- 默认检测内置中文字幕，已有明确标注的完整中文字幕时跳过；可选仅中英字幕时跳过或关闭检测。已知强制、路牌及特效轨道不作完整字幕，硬字幕无法检测。
- 默认按时长辅助筛选，接口结束时间仅作预排序，下载后核对正文。明显超出视频的候选排除，明显偏短的候选降分并提示；正常片尾无对白不扣分。
- 媒体信息通过 ffprobe 读取，超时 8 秒；配置可填写容器内可执行文件绝对路径，留空自动查找。检测失败继续普通下载并在记录中说明。
- 停用或重载会取消待执行任务；已开始的网络请求按超时结束，停止后不再保存字幕和记录。

仅处理可直接读取的实际视频文件；不处理未挂载云盘、STRM、蓝光/DVD 目录、RAR/7z 和图片字幕。
不扫描全片帧、不做音频对齐或校正时间轴。字幕结束时间不是影片总时长，不能识别几秒的固定偏移；名称和 CID 结果仍可能包含不同剪辑版，字幕同步需要播放确认。

## 验证

使用 MoviePilot V3.2.3 官方源码、Python 3.14 和宿主锁定依赖进行加载测试。
测试覆盖真实事件总线到宿主一次性任务的处理、字幕文件保存、配置与历史兼容、启停、重复初始化及市场代际选择。
字幕网络请求在自动测试中使用替身，不依赖公网字幕或真实媒体库；V3 网页界面和真实电影播放尚未实测。

完整配置说明见[仓库首页](https://github.com/lj0014/MoviePilot-Plugins)。
