# 迅雷字幕

整理入库后合并视频 CID 匹配与 HTTPS 名称搜索结果，下载中文字幕，无需额外字幕服务器或 API 密钥。

启用插件后自动处理新入库文件。补全已有影片时，填写 MoviePilot 容器内的扫描目录，打开“保存后扫描一次”；也可填写 cron 定时扫描。

字幕保存为 `影片名.zh.srt`、`影片名.zh.ass` 等同名文件。默认跳过已有外置中文字幕，始终保留原有同名文件。支持 UTF-8 保存、字幕偏好和最近 50 条处理记录。

新入库文件保留原始名称作为匹配线索，按原名和入库后文件名补搜，按下载地址合并去重。比较片源、剪辑版及发布组，并按语言偏好选择字幕。下载记录显示字幕来源、查询入口和匹配依据。扫描已重命名文件时只能使用当前文件名。

1.3.0 默认检测内置中文字幕：已有明确标注的完整中文字幕时跳过，可改为仅中英字幕时跳过或关闭检测；已知强制及特效轨道不作完整字幕。判断依赖轨道标签，无法识别画面硬字幕。

默认使用视频时长与字幕结束时间排查明显异常。接口时间仅作预排序，下载后核对正文；过短候选降分，正文结束时间明显超出视频的候选排除。片尾无对白不能视为不匹配，也不按时长差越小越好来排序。最多尝试 10 个候选，不校正时间轴，固定偏移仍需播放确认。

上述检测通过运行环境的 ffprobe 读取媒体信息，超时 8 秒，不扫描全片帧或做音频对齐。可在配置中填写可执行文件绝对路径；检测失败继续普通下载，处理记录会说明原因。两项检查均可关闭，原有配置保留。

仅处理本地或挂载到本地文件系统的实际视频，不能直接读取未挂载云盘或 STRM 内容。不支持 RAR、7z、蓝光目录、DVD 目录和图片字幕。

完整说明见 https://github.com/lj0014/MoviePilot-Plugins 。
