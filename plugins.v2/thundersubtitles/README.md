# 迅雷字幕

整理入库后按视频 CID 下载中文字幕，无需额外字幕服务器或 API 密钥。

启用插件后自动处理新入库文件。补全已有影片时，填写 MoviePilot 容器内的扫描目录，打开“保存后扫描一次”；也可填写 cron 定时扫描。

字幕保存为 `影片名.zh.srt`、`影片名.zh.ass` 等同名文件。默认跳过已有外置中文字幕，始终保留原有同名文件。支持 UTF-8 保存、字幕偏好和最近 50 条处理记录。

仅处理本地或挂载到本地文件系统的实际视频，不能直接读取未挂载云盘或 STRM 内容。不支持 RAR、7z、蓝光目录、DVD 目录和图片字幕。

完整说明见 https://github.com/lj0014/MoviePilot-Plugins 。
